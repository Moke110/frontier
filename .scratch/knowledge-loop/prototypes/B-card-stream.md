**📄 1/4 ｜ Truecell：Python 里原样复刻 R 的 Seurat**

作者自己明说的一句话是重点：*吻合反映的是对 Seurat 的**忠实**，而非**生物学正确***。

- **做了什么**：Seurat 的 Python 复刻，函数名 / 参数 / 默认值 / 对象模型全保留，让需要 Python 生态的实验室不必再「换个语言就换个结论」
- **发现**：18 组配对端到端评测，与 R Seurat 吻合到浮点精度；三臂基准（3 数据集 × 20 随机种子）里 12 个「数据集 × 分辨率」组合全部比「按 Seurat 配置的 Scanpy」更接近 Seurat
- **为什么重要**：语言生态分裂本身就是一种「参考实现不统一」；而「与参考实现对齐」是可测的**代理**，「分析结论生物学上对不对」才是**真目标**
- **保留**：复刻得精确 ≠ 更接近真相 —— 它只复刻了 Seurat 的选择，含其默认值与偏倚

**📄 2/4 ｜ scXMatch：把「两图看起来不一样」换成有统计根基的检验**

- **做了什么**：单细胞里「两组条件到底有没有整体分布漂移」现在靠目视 UMAP/t-SNE 或跑个聚类下判断 —— 作者直言这些做法「缺统计根基、出了名地不稳定、易受确认偏误影响」
- **发现**：非参数图检验，在基因表达 / ATAC / 影像形态三类数据上稳健检出漂移，Python 源码与复现脚本已开源
- **为什么重要**：直击本库「评测基准是否测到真目标」那条线 —— 凡「两图看起来不一样」的结论，先问有没有一个不依赖画图与调参的统计量撑着
- **保留**：检验自身也可能调（距离度量、阈值），摘要未报跨数据集复现

**📄 4/4 ｜ CatBoost 无创预测病因不明肝病纤维化：AUC 0.827**

- **做了什么**：武汉协和 503 名肝活检患者，12 种 ML 算法 + SHAP 可解释性，对比 FIB-4 / GPR / Forns / 单用 LSM
- **发现**：CatBoost 最好，AUC 0.827（95% CI 0.754–0.900），关键分类指标全面胜过常规对照
- **为什么重要**：模型想替代的**肝活检是金标准**，AUC/LSM 是**代理读数**；且按本库验证分级属**第①档**（只内部验证）—— 又一次「中小规模表格数据 → 经典方法常胜」
- **保留**：单中心、回顾性、无外部队列；SHAP 排序好看但需防循环特征
