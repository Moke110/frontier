**Truecell：在 Python 里原样复刻 R 的 Seurat —— 但作者明说「吻合反映的是对 Seurat 的忠实，而非生物学正确」**

`arxiv:2610.10482v1` ｜ PDF 已存

- **做了什么**：单细胞分析被 R 的 Seurat 与 Python 的 Scanpy 瓜分，默认设置下二者给出的高变基因、近邻图、聚类、标志基因都不一样；需要 Python 的实验室只能把 Seurat 分析重实现在一个不复刻其结果的框架里 —— 同一批数据换个语言就换个结论。作者做了 **Truecell**：保留 Seurat 函数名、参数、默认值与对象模型的 Python 版。
- **发现**：18 组配对端到端评测中，确定性输出与 R Seurat 吻合到浮点精度，9 项差异表达检验的变化倍数排序完全一致；三臂基准（3 数据集 × 每工具 20 随机种子）里 12 个「数据集 × 分辨率」组合 Truecell 全部更接近 Seurat；pseudobulk + DESeq2 复现 Seurat 基因列表的 Jaccard 0.95–1.00。
- **为什么重要**：本库「先统一怎么比、再谈强弱」与「可比性」这条线的又一实例 —— 语言生态分裂本身就是「参考实现不统一」。**最该记下的是它自己承认的那句**：*This agreement reflects fidelity to Seurat rather than biological correctness.* 这正是「**代理 vs 真目标**」：与参考实现对齐是**可测的代理读数**，分析结论在生物学上对不对才是真目标；复刻得再精确，也只是复刻了 Seurat 的选择（含其默认值与偏倚）。
- **保留**：这是「工具一致性」评测，不是生物学基准 —— 读者勿把「一致」误读为「更准」。
