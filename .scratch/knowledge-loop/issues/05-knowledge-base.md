# 05 知识库载体与粒度

Type: grilling ｜ Status: resolved ｜ Blocked by: 03
Claimed by: Hermes (session 2026-10-16)

## Question

「知识库（我已知什么）」的**载体、粒度、写入权**怎么定？

旧系统形态（`cron-digest-pipelines` skill 记录）：`knowledge/<field>.md`，四段（**认知摘要 / 术语表 / 跟进脉络 / 盲区**），agent 推送前读、推送后写；用户改「盲区」来引导选题方向。

## 侦察事实（从 8 份旧日报反推 —— 知识库正文未幸存）

`knowledge/demo_ai4bio.md`，**一个域一个文件**。09-25 曾「重建（术语表 9 条 + 09-05~09-25 脉络 + 盲区回填）」；此后每天：术语表 **+6~11 条**、脉络 **+1 行**、盲区回填。

最关键：日报的「为什么值得看」段落**天天引用写在该文件里的盲区** ——「缺统一评测/基准」「代理 vs 真目标」「DL vs 经典」「报增益须同时报在哪些子集失效」「指标↔真目标的三个解毒剂」。

→ **旧知识库真正值钱的资产是「盲区」，它已长成一套判断框架**，不是术语堆。

→ 同时暴露了它的病根：**三种不同的读写模式被塞进一个文件** ——

| 段落 | 本质 | 读写模式 |
|---|---|---|
| 术语表 | 字典 | 只增、按条更新 |
| 跟进脉络 | **时间序列** | 每天 append |
| 盲区 | **跨概念的判断框架** | 被不同域回填 |

混在一起 → 「越长越难读」＋ agent 每次要全读 → 撞 token 上限。

## Answer

**决策（用户）：B —— 双层，概念页 + 命题页，盲区附在各概念页里。**

- **概念页**（按 checkpoint）：一个概念一份 —— 字典式，放「我现在的理解 / 术语 / 我的判断」
- **命题页**（按 `related` 连通子图）：一条命题一份 —— 时间序列，放「这条线的进展」
- **盲区**：附在概念页内

**并且：知识库其余细节不再深入计划（用户指示）。** 第一阶段任务是 **checkpoint + 检索 + 评分反馈闭环**；知识库仅确定粒度方向（B），其余（载体格式、写入权与回退、token 消费方式、annotation 与知识库的权威边界）**推迟到第二阶段**，本图不再为它们建票。

### 风险记录（留给第二阶段，不要丢）

Hermes 建议的 A 方案（**盲区单独成一份跨概念清单**）被否决了，理由是保持结构简单。这里记下反对意见，供第二阶段复核：

> **盲区的价值恰恰来自跨域复用。** 「代理 vs 真目标」这一条在单细胞、临床影像、眼科 AI 上都成立；一旦按概念拆散到各个概念页，你就再也看不到「**同一形状出现了第 7 次**」。旧日报里最有力的段落，全部是这种跨域计数（「与 09-27 骨折、09-27 眼科同一形状」）。

→ 第二阶段若发现「盲区在概念页里零散、无法复用」，这是重新考虑 A 的信号。

### 对第一阶段的直接后果（必须让 spec 知道）

**没有知识库，卡片会「断史」。** 卡片的「为什么重要」原本靠知识库撑起「这是同一形状第 7 次」这种跨篇连接；第一阶段不做知识库 → 卡片只能讲这篇本身。

**廉价替代（建议写进 spec，不算知识库）**：用 `archive/papers.jsonl`（已推送过的 title + 一句话 gist + checkpoint 归属）当**轻量脉络**，让卡片能说「本 checkpoint 近 N 次命中里，这是第 2 次出现『代理 vs 真目标』」。这不引入新的知识库结构，只是把已有归档多用一个维度。
