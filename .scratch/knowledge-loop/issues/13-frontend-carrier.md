## Question

微信 gateway 只给纯文本：**不能图文并茂、没有按钮/控件、PDF 不能预览**。票 02 与票 10 的每一条硬约束（单条 <4000 字符 · 无按钮 · 唯一结构化输入是「编号 + 回数字」· 引用不带 id · DM-only）都是**这个载体的产物**，不是问题的本质。

调研并排序一种（或少数几种）**推送 + 交互前端**，满足：

1. **免费部署**（免费额度够单人日常；不要信用卡/不要企业认证为宜）
2. **远程访问**（我在手机上、不在 LAN 内，也能打开并交互）
3. **HTML 渲染**（卡片正文能带富文本：标题层级、链接、图、公式、代码块）
4. **PDF 渲染**（文章 PDF 能在同一界面里预览/翻页，不必下载再找 App 打开）
5. **非文本交互**（三档评分要能以**控件**形式一键点；追问/收藏同理）
6. **入站可写回**（我的点击/评分必须能被 WSL 上的 Hermes cron 读到，驱动反哺）

## 每个候选必须给出的评估维度

| 维度 | 要具体到 |
|---|---|
| 免费额度 | 存储/请求/构建次数的**数字**，超限怎么计费 |
| 部署成本 | 是否需要域名、证书、信用卡、实名/企业认证 |
| 国内可达性 | **是否需要翻墙**；不翻墙时的延迟与稳定性 |
| HTML 渲染 | 能到什么程度（自定义 CSS？KaTeX/MathJax？外链图？） |
| PDF 渲染 | 内嵌阅读器 / pdf.js / 只能下载 / 只能看摘要 |
| 非文本交互 | 按钮/单选/多选/评分控件的原生程度；回调怎么回来 |
| 入站通路 | 我的动作 → 本地 WSL 的具体链路（webhook？轮询？文件同步？） |
| 通知 | 有没有真·推送（锁屏可见）；还是必须我主动打开 |
| 运维负担 | 单人要维护几个东西；坏了怎么发现 |
| 风险 | 免费额度政策变更史、封号史、国内屏蔽史 |

## 侦察结果（2026-10-19，调研已完成 —— 只差用户拍板）

**完整报告**：[`../research/13-frontend-carrier.md`](../research/13-frontend-carrier.md)（435 行：11 候选 × 11 维对照表 + 国内可达性实测 + 3 个组合方案与最小上线步骤 + 免费额度速查表 + **12 条未核实项清单**）。

**本机实测（2026-10-19 15:00 CST，单网络单时刻，只作定性判断）**：

| 目标 | 结果 |
|---|---|
| `open.feishu.cn` | 200 / **0.027–0.035 s** |
| `*.workers.dev` | **15 s 超时**（TCP/SNI 层阻断） |
| `api.telegram.org` | **15 s 超时**（被墙） |
| `*.pages.dev` | 系统 DNS 会投毒到 `127.0.0.1`；`--resolve` 真实 CF IP 时 1.1–5.8 s / 522 —— **可达但边缘慢** |
| `*.vercel.app` / `*.netlify.app` | 15 s 超时 / 立即失败（控制台域可通） |
| `*.gitee.io` | 404（Gitee Pages 事实已下线） |
| `ntfy.sh` / Bark / PushDeer | 0.6–2.1 s 通 |

**排名结论**：

1. **飞书自建应用**（消息卡片 + 长连接回调 + 文件消息送 PDF）—— 唯一同时满足「国内直连 + 锁屏真推送 + 原生按钮 + 无需公网 IP / 域名 / 备案 / 信用卡」。回调经 WebSocket 长连接直接落进 WSL。
2. **Cloudflare Pages（自有域名）+ Workers + D1 + ntfy/Bark** —— 渲染零妥协（任意 HTML、KaTeX、pdf.js 内嵌翻页），但 `pages.dev` / `workers.dev` 裸域不可用 → **必须自购域名**，国内首屏 3–8 s。
3. **自建 FastAPI（WSL）+ Cloudflare Tunnel / Tailscale Funnel** —— 掌控最强，代价是 WSL 常开 + 隧道单点。

**硬天花板（免费额度下做不到，详报告 §7）**：飞书卡片 ≤30 KB / ≤200 组件 / 回调 3 s 内必须返回 / 卡片里**不能**嵌 PDF 翻页器（只能发 `file` 消息或跳链接）· CF 免费版拿不到中国节点 · Android 上 PWA 推送走 FCM 不通 · GitHub Pages 免费版强制公开仓库（评分记录会公开）· Supabase 免费项目 7 天无活动暂停。
