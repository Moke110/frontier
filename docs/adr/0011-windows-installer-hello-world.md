# ADR 0011：Windows 安装器与 Hello World 首次运行

日期：2026-11-05。状态：已接受，待实现。用户通过 grill-with-docs 确认本阶段只交付“发布 → 安装 → 运行 Hello World”。现有 ZIP 分发与宿主初始化流程无法提供该体验，因此以 GitHub Release 的 Windows `.exe` 安装器作为用户入口；这是对 ADR 0010 用户安装入口的修订，不废除其自包含运行时原则。既有业务源码保留，本阶段安装与运行不启动宿主、飞书、调度或初始化流程。该阶段边界避免首次运行依赖尚未验收的业务配置。

## 已确认的交付边界

- 支持 Windows 10/11 x64，仅为当前用户安装；默认目录 `%LocalAppData%\Programs\Frontier`，安装向导允许修改，默认安装无需管理员权限。自选目录仍须具有写权限。
- 安装目录提供 `Frontier.exe`，创建开始菜单入口；桌面快捷方式为安装时可选项。支持从 Windows“已安装的应用”卸载。
- 双击 `Frontier.exe` 打开独立的 Windows 控制台窗口，标题为 `Frontier Console`，显示 `Hello World`，保持打开直到用户关闭。
- 安装器包含运行所需文件；安装和启动不依赖联网、用户预装 Python 或开发工具链，不要求登录或配置宿主。
- 重复安装可覆盖安装或升级同一目录；替换前要求关闭运行中的 Frontier。本阶段不提供自动更新或版本回滚界面。
- 交付新的 GitHub 预发布版本，提供 `.exe` 安装器。既有 Release 保留，旧版 ZIP 的验收不算本阶段验收。

## 验收边界

从新 Release 下载真实安装器，完成安装目录选择、开始菜单与可选桌面入口、启动显示及卸载的实际验证。选定的测试安装路径包含空格和中文；验证默认目录安装无需提权，验证重复安装或升级时对运行中进程的处理。确认安装后直接双击 `Frontier.exe` 即显示准确的窗口标题与 `Hello World`，无需业务配置，并验证无网络及无系统 Python 依赖。

实现选用的安装器工具、可执行入口技术和具体版本号由实现阶段确定；本决策不要求将现有 Python 业务整体编译。代码或构建测试通过不能代替从 Release 下载的安装器实测。当前尚无本阶段实现或验收通过的声明。
